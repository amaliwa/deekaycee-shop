# Deekaycee Shopping & Shipping

Starter workspace for local website development with PHP, WampServer, and VS Code.

## Local setup

1. Open this folder in VS Code.
2. In WampServer, make sure Apache is running.
3. Create a junction or copy this folder into `C:\wamp64\www` if you want to use the Wamp Apache URL:
   `http://localhost/deekaycee-shopping-and-shipping/`
4. For a quick PHP-only preview, run `php -S localhost:8000` from this folder.

Do not commit `.env` files or hosting credentials. Remote deployment should be configured only after the hosting provider and authentication method are chosen.
